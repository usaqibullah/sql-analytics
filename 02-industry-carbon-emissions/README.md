# Industry Carbon Emissions Analysis Using SQL

## Project Overview

This project explores industry carbon emissions data using SQL. It focuses on analyzing information across multiple tables and practicing SQL techniques to retrieve and organize data.

## Objectives

* Explore industry carbon emissions data.
* Analyze information using SQL queries.
* Combine related datasets to examine information across tables.
* Practice extracting meaningful insights from data.

## Tools Used

* SQL
* DataCamp
* PostgreSQL

## Skills Practiced

* SQL Joins
* Data Manipulation
* Data Filtering
* Data Exploration
* Data Analysis

## Project Files

The SQL file for this project contains the queries used to explore and analyze the dataset.
