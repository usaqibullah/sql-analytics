# Analyzing Student Mental Health Using SQL

## Project Overview

This project explores student mental health data using SQL. It involves examining the dataset and using SQL queries to investigate information related to students' mental health.

## Objectives

* Explore student mental health data.
* Examine patterns in the available dataset.
* Retrieve and organize information using SQL.
* Practice SQL-based data analysis.

## Tools Used

## Skills Practiced

* Data filtering

* Data analysis
