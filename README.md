# International Debt Statistics Analysis Using SQL

## Project Overview

This project explores international debt statistics using SQL. The goal is to work with real-world debt data, examine the available information, and practice extracting meaningful insights through SQL queries.

## Objectives

* Explore international debt data.
* Analyze debt-related information using SQL.
* Retrieve and organize relevant data.
* Practice solving data analysis problems with SQL.

## Tools Used

* SQL
* DataCamp
* PostgreSQL

## Skills Practiced

* SQL querying
* Data exploration
* Data filtering
* Data aggregation
* Data analysis

## Project Files
